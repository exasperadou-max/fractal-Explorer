# Fractal Explorer

A browser-based fractal explorer built with HTML, CSS, JavaScript and WebGL.

Explore different fractals in real time, zoom into them, change colors and create your own custom fractals.

## Features

* Mandelbrot, Julia, Burning Ship, Tricorn, Multibrot, Celtic and Phoenix fractals
* Custom fractal generator
* Multiple color palettes and custom palettes
* Smooth zooming and panning
* Mouse, keyboard and touch controls


## Controls

* **Drag** : Pan around
* **Scroll / Click** : Zoom in and out
* **Right-click**: Zoom out
* **+ / -**: Zoom in/out
* **0** : Reset view
